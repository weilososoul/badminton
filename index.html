貼個清單落去，自動計出每人應付 / 應收。 · 版本 23Oct-C

每人打幾多個鐘預設跟足成個時段；有人打半場嘅話，tick 咗佢之後喺個名後面揀返邊段。計完會自動存落下面「📜 記錄」。想幾日一齊結數？每填好一日撳「➕ 加落呢批」，改個日期 tick 返嗰日啲人，再填下一日，齊咗撳「🧮 計晒成批」，各人幾日嘅數會自動夾埋出總數。

☁️ 跨機同步（Supabase 免費；唔填就完全唔會上網）

開法（一次過，約 5 分鐘）：去 supabase.com 用 GitHub 戶口開個免費 project → SQL Editor 貼下面段嘢撳 Run → 攞 Project URL 同 anon key 填上面 → 每部機都係咁填同一個同步碼。同步範圍：名單＋記錄＋收數 tick＋價錢設定（兩邊都有改動就以上次改嗰部機為準）。段 SQL：

📖 點計（睇下條數點嚟）
  • 場租 = 每個 book 場嘅費用加埋（普通場每鐘 $59；特別價場照價，已包埋波錢）
  • 場租部份按每人打嘅鐘數分攤（四捨五入至 $0.1，夾埋啱啱等於場租總額）
  • 波錢 = 每人每鐘 $15，只計「普通場開緊」嘅鐘（特別價場嗰啲鐘已包，唔使計）
  • 每人應付 = 場租份 + 自己波錢
  • Book 場嘅人有墊支，應收返墊咗嘅數；你收齊所有人嘅錢，再找返俾佢哋
  • 某個場有特別價？喺「場地明細」改嗰格，或者喺清單行尾加「 $360」。特別價 = 嗰個場嘅總數（已包埋波錢），唔會再另加波錢
  • 可以一次過貼幾個清單（例如兩三個禮拜嘅數一齊結）：下一份以「日期：」開頭會自動分開，或者中間加一行「=====」，各人條數會合併出總數
  • 簡單格式都認得：「1/10」淨一行當日期；「時間：10-1 (俊1→賢2→Cathy3)」= 10點至1點、邊個 book 咗邊個鐘；下面淨係名冇時間（1.俊）= 個個當打足成個 session
  • 「時間」行點寫都好：「下午7-9」「7-9pm」「7時-9時」「7至9」都識；「場地」行「Red」= Red book 一個場、「Red、Ken」= 兩個人各一個場、「Red#8、3」= Red book 咗 8、3 號兩個場 —— 時間跟「時間」行，場數跟名同場號
  • 「搞掂 ✓」欄勾一勾 = 記住邊個已俾錢／你已找返錢；記錄表會顯示「已收 x/y」，收齊變「✅ 收齊」
  • 「跟X」= 跟 X 嘅打波時間（以打波名單嘅時間為準，唔係佢 book 場嘅時間）
